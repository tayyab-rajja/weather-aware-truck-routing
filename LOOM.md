# Loom walkthrough script (5–10 min)

Record this exact flow — nothing extra.

1. **Intro (30s)** — “Weather-Aware Truck Routing: React + Django app that picks the safest truck route using weather, load weight, and travel time.”
2. **Form (1 min)** — Enter origin, destination, departure, load weight, sample interval (10/25/50). Submit.
3. **Three routes (2 min)** — Show map with all routes; click each route card; call out distance, time, severe/high miles, avg risk.
4. **Recommended route (1–2 min)** — Explain the preference order: fewest Severe → fewest High → lowest avg risk → shortest time. Read the “why recommended” line.
5. **Checkpoint risk (2 min)** — Click a checkpoint marker; show ETA, wind/rain/snow, risk level, and reasons (including a load override if weight is high).
6. **48h heatmap slider (1–2 min)** — Scrub the forecast slider; show heatmap colors changing along the corridor.
7. **Close (30s)** — Point to GitHub README for setup, risk table, and hosted URL.
