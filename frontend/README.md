# Frontend — Weather-Aware Truck Routing

Vite + React + TypeScript + Mapbox GL JS with free Esri street/satellite tiles (no map API key required).

```bash
npm install
cp .env.example .env   # VITE_API_URL=http://localhost:8000
npm run dev
```

Optional: `VITE_MAPBOX_TOKEN` for Mapbox vector basemaps. Without it, Esri raster tiles are used.
